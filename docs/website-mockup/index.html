What we do

We pick an idea, set a short deadline, and use AI to get from nothing to something playable. Then we do it again.

// jams

Game, app and program jams

Short, focused builds with a theme and a deadline. You'll ship more in a weekend than in a month alone.

// ai

AI as a teammate

We lean on AI for code, art, writing and debugging, and we share what works so everyone gets faster.

// later

The long game

We're building toward a company that helps businesses build with AI. People who join early help shape it.
